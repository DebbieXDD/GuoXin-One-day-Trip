## 🗺️ 行程動線總覽（順路不走回頭路）

> **出發月份**：11月（秋高氣爽、約 17:10 日落）  
> **出發地點**：南投草屯（當天來回）  
> **交通方式**：爸爸開車（去程國道6號或台14線、回程順走台14線中潭公路避車潮）  
> **核心理念**：不走回頭路、各景點好停車、傍晚天黑前回到草屯吃晚餐，吃完 5～10 分鐘輕鬆到家！

```
09:00 草屯出發 ➔ 09:30 北山米苔目（早午餐） ➔ 10:40 九份二山地震園區 ➔ 12:30 元寶土地公廟（參拜＆輕食） ➔ 14:00 國姓精品咖啡廳（三選一） ➔ 15:45 橋聳雲天/買伴手禮 ➔ 17:15 返回草屯吃晚餐 ➔ 溫暖的家
```

### 🕒 行程重點摘要

1. **09:00 - 09:30｜草屯出發 ➔ 國姓北山**
   * 走 **國道6號（東草屯 ➔ 北山交流道）** 或順走 **台14線（中潭公路）** 賞九九峰山景。
2. **09:30 - 10:30｜【美食】北山米苔目（在地70年老店）**
   * 中午前常完售，必排第一站！吃完順買斜對面「北山冰店」帶皮檸檬汁。
   * 🅿️ 建議停在「北山派出所」或郵局前後白線處。
3. **10:40 - 12:20｜【地景】921 九份二山國家地震紀念地**
   * 趁早上精神好開山路，順遊：**傾斜屋 ➔ 震爆點 ➔ 雙堰塞湖（澀仔坑湖、韭菜湖）**。
4. **12:30 - 13:45｜【祈福】國姓「元寶土地公廟」＋午間輕食**
   * 下九份二山回投147縣道必經，附設**超大免費停車場**。摸金元寶奇石、轉 108 顆「石來運轉」石球求平安財運。
   * 🍴 **午餐推薦（皆附停車場）**：**鄉之味-老地方餐廳**（國姓老街口，精緻客家菜）或 **136公路客家小館**（台14線旁、去咖啡館超順路）。
5. **14:00 - 15:45｜【午茶】國姓精品咖啡時光（三選一）**
   * **A. 九二咖啡故事館**（台14線旁、農會舊穀倉改建、大停車場）
   * **B. 山間良物**（九九峰山腳老宅庭園秘境、近國姓交流道）
   * **C. 鐵帽咖啡**（台14線旁、半戶外開闊山谷景觀）
6. **15:45 - 16:45｜【順遊】橋聳雲天綠雕園區 或 11月限定「國姓搶成功」**
7. **17:15 - 19:00｜【晚餐】返回草屯家庭聚餐（三選一，皆附停車場）**
   * 趁 16:40 天色還亮順走 **台14線（中潭公路）** 回草屯，避開國道塞車與夜間山路，吃完 5 分鐘到家：
   * **1. 春水岸料理茶房**（草屯新富路，功夫簡餐與小火鍋，長輩最穩首選）
   * **2. 湫禾壽喜燒 / 田中央涮肉**（草屯碧山路，11月微涼吃鍋首選）
   * **3. 巷仔內田庄味土雞料理**（草屯墩煌路，紅磚古厝脆皮桶仔雞＆台菜合菜）
